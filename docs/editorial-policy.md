# Paper data and selection / 论文数据与筛选方法

本页说明研究雷达的数据来源、日期、去重、筛选和论文注释规则。

## 公开内容的职责

研究雷达累计保存最终收录的新论文。首页默认按时间倒序展示全部收录，每页 20 篇，提供全库搜索、时间与四个研究方向筛选。分页只控制浏览密度，不代表收录配额；不用旧论文补足数量。页面显示的是已收录论文的时间跨度，不表示完整覆盖。

公开页面只收录三类研究事件：

- `new-preprint`：新预印本首次公开；
- `major-revision`：新增主要定理、核心方法、实验、实质分析或改变主要结论的重大修订；
- `journal-publication`：首次正式在线期刊发表。

普通文字润色、参考文献、排版、作者顺序、元数据和小范围勘误不构成重大修订。

## 日期与重复记录

新预印本按 arXiv 官方公告日期排序，提交日另作书目信息保留。首次正式发表采用出版商的在线日期；DOI 注册、索引入库或后来分配卷期的日期不会被当作新发表日期。

同一工作只保留一个条目。已收录的预印本正常见刊时补充期刊信息，不重复推荐；只有新增主要定理、核心方法、实验或实质分析的修订才作为新的研究事件处理。

## 筛选原则

重点关注可积非线性波、逆散射与谱方法，包括适定性、稳定性、长时间渐近、孤子与呼吸子、有限隙背景和孤子气体。收录依据是实际研究问题的实质进展，或与这些问题建立具体方法联系的新方向。

概率、几何、量子理论、数值和实验均可能提供有价值的联系，但本站不追求这些领域的全面覆盖。作者、学科标签或期刊本身不决定收录，每日和每周也不设篇数配额。

延迟发现仍沿用真实事件日期。同一工作的预印本与正式发表合并为一个条目；元数据更新不会被包装成新研究事件。公开文字说明入选论文，不公开逐篇否定性评价。

## 数据来源与核验

| 来源 | 用途 |
| --- | --- |
| [arXiv nlin.SI](https://arxiv.org/list/nlin.SI/recent)、[nlin.PS](https://arxiv.org/list/nlin.PS/recent) 及相关分类 | 发现预印本和修订，核对题名、作者、摘要与版本 |
| [Crossref](https://www.crossref.org/) | 通过题名与 DOI 补漏、匹配期刊书目 |
| [zbMATH Open](https://zbmath.org/) | 利用数学专业分类发现题名检索可能遗漏的论文 |
| 出版商页面与论文全文 | 核对首次在线日期、正式书目和具体结论 |

普通网页检索和作者页面用于发现线索。最终条目链接到 arXiv 或 DOI；不同来源的覆盖范围有限，本站不宣称检索完全。课题组页面的可查询书目组件与首页精选列表各有用途，组件结果不自动成为首页推荐。

展开内容分别说明研究问题、主要结果、方法和具体新增内容，并区分定理、数值证据与猜想。摘要可支持简要介绍，超出摘要的技术细节需回到全文核验。

## AI 与人工审核

AI 用于候选发现、元数据核验、初步筛选、文字整理、页面生成和一致性检查。除非特别注明，公开说明不表示编辑已经完成全文逐句审校或独立验证数学证明。

每次实际变更通过可审核 PR 提交。CI 成功不代表合并批准；是否合并由项目维护者明确决定。
